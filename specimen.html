02 Conjunct & matra stress test

05 Character set

The exact coverage of every Kalpurush file (identical across all six styles): 91 Bengali codepoints, the full printable Latin range, digits and punctuation.

Bengali — 91 characters (U+0980–U+09FF)

ঁংঃঅআইঈউঊঋঌএ ঐওঔকখগঘঙচছজঝ ঞটঠডঢণতথদধনপ ফবভমযরলশষসহ় ঽািীুূৃৄেৈোৌ ্ৎৗড়ঢ়য়ৠৡৢৣ০১ ২৩৪৫৬৭৮৯ৰৱ৲৳ ৴৵৶৷৸৹৺

Includes all vowel signs (া ি ী ু ূ ৃ ৄ ে ৈ ো ৌ), the bare forms ঽ ়, conjunct marks ্ ৎ ৗ ড় ঢ়, Bengali digits ০–৯, ৰ ৱ ৲ and the Bengali rupee sign ৳.

Latin — 95 characters (U+0020–U+007E)

!"#$%&'()*+ ,-./01234567 89:;<=>?@ABC DEFGHIJKLMNO PQRSTUVWXYZ[ \]^_`abcdefg hijklmnopqrs tuvwxyz{|}~

Plus general punctuation: en/em dash – —, quotes ' ‘ “ ”, ellipsis …, minus sign −, ZWJ/ZWNJ and combining dotted circle (matra base).

07 Install & use

Web — via CDN (no files needed)

<!-- one line loads all six styles -->
<link rel="stylesheet" href="kalpurush.cdn.css">
<style>
  body { font-family: "Kalpurush", serif; font-weight: 600; }
</style>

The CDN stylesheet references jsDelivr, which serves the font files straight from this repository. If you host the files yourself, kalpurush.css (relative paths) and kalpurush.scss (Sass, configurable path) are ready to use.

Desktop — install the font files

  1. Windows: select all ttf/*.ttf → right-click → Install for all users.
  2. macOS: open ttf/*.ttf in Font Book → Install Font.
  3. Linux: copy to ~/.local/share/fonts, then fc-cache -f.

After installing, “Kalpurush” appears as one family — Regular / Italic / Bold / Bold Italic. The two SemiBold styles show up as a separate family “Kalpurush SemiBold” in apps that don’t read weight-based families (e.g. Word), and as weight 600 of “Kalpurush” in browsers/CSS.

Design apps

Drop the ttf/ files into your project and use the family name Kalpurush — SemiBold is weight 600, Bold is 700, Italic is font-style: italic.

Rebuilding the styles yourself

# tweak STYLES / ITALIC_ANGLE / VERT_RATIO at the top of the script
pip install fonttools skia-pathops brotli
python source/build_kalpurush.py Kalpurush.ttf out

See source/build_kalpurush.py for the full method: emboldening via outline offsetting (skia-pathops stroke + union), a 12° oblique italic skew with skewed GPOS anchors, and no changes to GSUB/GPOS/cmap — so shaping is identical to Regular.

08 License & credits

Kalpurush is released under the SIL Open Font License 1.0 — free to use, study, modify and redistribute, including commercial work, as long as the license is preserved.

The font carries no Reserved Font Name clause, so derivatives may use the name “Kalpurush”. (If you obtain a copy from elsewhere, verify the embedded license first — change the FAMILY constant in source/build_kalpurush.py if it declares one.)
